# RB-11 · The nightly scoring run did not fire

owner: data team · as of 2026-10-20 · readers: everyone

## Symptom

No new scores file in the bucket this morning, and no `START` line in the batch function's log overnight.

## Check the rule

The run is started by an EventBridge rule named `score-nightly` with a schedule expression such as `cron(0 7 * * ? *)` (07:00 UTC) or, for the lab, `rate(5 minutes)`. Check that the rule's state is `ENABLED`: `aws events describe-rule --name score-nightly --region us-east-1`. A rule created with `schedule.sh --off` is disabled.

## Check the target and the permission

The rule needs a target, the batch function, and the function needs a resource permission for the principal `events.amazonaws.com`. `aws events list-targets-by-rule --rule score-nightly` shows the first; `aws lambda get-policy --function-name score-batch` shows the second. `schedule.sh` creates both; if the function was deleted and recreated, the permission is gone and must be added again.

## Rules fire without a session

The rule fires whether or not your Learner Lab session is running. If it did not fire, the cause is the rule, the target or the permission, never the session.
