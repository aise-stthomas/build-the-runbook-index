# RB-22 · The Swagger page does not open

owner: platform team · as of 2026-10-22 · readers: everyone

## On the laptop

The page is at the API's URL with `/docs` on the end, for example `https://abc123.execute-api.us-east-1.amazonaws.com/docs`. Locally it is `http://127.0.0.1:9000/docs`. A blank page with the URL right usually means the function is returning 502: check the log, RB-07.

## On the phone

If the page opens on the laptop and not on the phone, the phone's network is the usual cause: campus guest networks block some hosts. Try mobile data. Copy the URL from the output of `deploy.sh` rather than typing it; the API id is random letters and one wrong character gives a page that never loads.

## The Authorize button is missing

The token header is declared as an API key in the app so that Swagger shows the button. If the button is missing, the deployed code is older than the one on your laptop: run `./deploy.sh` again.
