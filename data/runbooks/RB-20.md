# RB-20 · Changing the golden set

owner: measurement team · as of 2026-10-22 · readers: everyone

## The rule

The golden set is versioned. Every change bumps the version in `data/golden/README.md` and the file's hash is recorded with every run that used it. A rate measured on version 3 is not compared with a rate measured on version 4.

## When you add tickets

Add them to a slice, or make a new slice. A ticket without a slice is a ticket whose rate nobody owns. Rerun the noise floor on the slice: three runs of the unchanged system, so the new tickets' variance is known before any change is measured against it.

## When you change an expected answer

Write down why, in the ticket's record. If two people disagree about the expected answer, the disagreement is the requirement not yet written; settle it in the policy text first.

## Do not

Do not remove a ticket because the system fails it. A failing ticket is a measurement.
