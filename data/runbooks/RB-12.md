# RB-12 · The scores file is missing from the bucket

owner: data team · as of 2026-10-20 · readers: everyone

## How a run publishes

A run writes its scores file under `runs/<run id>/scores.jsonl`, then runs its check (the row count against the account count, and the score distribution against last night's), and only if the check passes moves the pointer `current.json` to the new run. A run whose check failed leaves its file in place and the pointer where it was.

## Diagnosis

List the runs: `aws s3 ls s3://<bucket>/runs/`. If today's run directory exists but `current.json` points at yesterday, the check failed; its reason is in the run's `run.json` and in the log. If today's directory does not exist, the run never started: RB-11.

## Rerun

`uv run run_batch.py --date 2026-10-20` reruns one date. It is idempotent: the same date produces the same file and replaces it. Do not edit `current.json` by hand; the pointer only moves when a check passes.
