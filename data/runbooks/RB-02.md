# RB-02 · Rotate the model key

owner: platform team · as of 2026-10-19 · readers: everyone

## When to rotate

Rotate the Gemini key when it has been pasted anywhere it should not have been: a chat message, a screenshot, a commit, a classmate's laptop. Also rotate it at the end of every semester.

## Steps

1. Create a new key in Google AI Studio at aistudio.google.com/apikey.
2. Replace the `GEMINI_API_KEY` line in `.env`. Never put the key in a source file.
3. Run `./deploy.sh` again. The deploy script copies `.env` into the function's environment variables, so the function only sees the new key after a redeploy.
4. Delete the old key in AI Studio. A deleted key fails with HTTP 400 and the message "API key not valid", which is how you know the old key is gone everywhere.

## Exception

If a classmate's deployment is using your key because theirs was broken on lab night, tell them before you delete the old one. Their function will fail with the same 400 until they redeploy with a key of their own.
