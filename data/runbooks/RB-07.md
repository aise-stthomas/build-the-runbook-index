# RB-07 · The API answers 502 or 503

owner: platform team · as of 2026-10-19 · readers: everyone

## 502

The function crashed or returned something the gateway could not deliver. Look in the log for a `Traceback`, or for `Task timed out` (RB-04). A 502 with `Runtime.ImportModuleError` means the package is missing a dependency: check that `deploy.sh` built the package for the Linux platform and not for your laptop.

## 503

The function ran and gave up on the vendor: a daily quota that is used up, or a provider that keeps returning 5xx. The response body says which. Check the key in `.env` (RB-02) and whether the quota is the daily one (RB-01). Redeploy after fixing `.env`, because the function reads its key from its own environment, not from your laptop.

## 502 from `/chat` only

The chat route asks for plain text and the triage route for JSON. A 502 from `/chat` alone, with a `ValidationError` in the log, means the reply did not fit the response model: usually an empty reply from the model after a safety block. Retry once; if it repeats, log the request and move on.
